INDEPENDENT PROCESSES:
- Displaying time on 7 segment display
- Motion sensor turning on and off system: when off the only thing being checked is the sensor
- Fan operation [speed, on/off]
- Fan movement [oscillation/custom angle]
- Auxiliary feedback like light and sound on different actions.
2 lcd pins + 1 pir sensor pin + 1 motor pin + 1 servo pin+ 1 analog joystick + 1 joystick button + 1 reg button + a buzzer
so 6-8 GPIO digital and 1 analogue
FAN OPERATION:
- motor driver
- A button should also be able to control the fan on it's own

FAN MOVEMENT:
- Two modes: Oscillation mode and custom angle mode
- Oscillation mode has the servo rotate back and forth
- custom angle mode reads the analogue input on the joystick to change the angle
- IMPORTANT NOTE: DO NOT MAP THE POSITION OF THE JOYSTICK TO SERVO, RATHER READ THE DIFFERENCE FROM EQUILIBRIUM POSITION TO DETERMINE RATE OF CHANGE
- to switch between the two, read joystick button

STATES:
- ON/OFF
- OSCILLATION/CUSTOM
