# PROJECT FAN
see title

The Idea:
A motion activated fan that can turn on/off from a wave by the user. It will have variable speeds for the fan, an RGB LED to notify the user of status and a 4-digit 7 segment display to display the time. In addition to this it will have an oscillating mode and a custom angle mode, switcheable with a button. A passive buzzer that outputs a tone on certain events

Requirements
- Oscillating fan head
- variable speed with potentiometer
- turns on via wave
- 7 segment display showing time
- Joystick controls custom angle
- 3D printed housing
- only using ESP8266

Components
- Micro-USB wire
- DC Motor
- Relay
- RGB LED
- Joystick
- 7 Segment display
- Motion sensor
- ESP8266
- 3D print at end
